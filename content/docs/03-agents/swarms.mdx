## Consensus Mechanism

```python
async def reach_consensus(
    agents: list[str],
    proposal: str,
) -> str:
    votes = await asyncio.gather(*[
        query_agent(agent, f"Approve or reject: {proposal}")
        for agent in agents
    ])
    approvals = sum(1 for v in votes if "approve" in v.lower())
    return "approved" if approvals > len(agents) / 2 else "rejected"
```

## Key Takeaways

- Use a coordinator agent for task decomposition and result aggregation
- Implement validator agents for cross-checking outputs
- Design clear communication protocols between agents
- Always include human-in-the-loop for critical decisions
